# TD;DW TV Recaps Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A small LAN web service that turns one TV-remote button press into a spoiler-free recap page for whatever Jellyfin is playing, with a phone view for follow-up questions.

**Architecture:** A zero-dependency Node service in `tv/` that reuses the extension's recap engine (`background/providers`, `background/llm-client.js`) and subtitle helpers (`content/adapters/jellyfin-subtitles.js`, `transcript-cap.js`). It finds the playing Jellyfin session (or the latest resume point), builds the same `videoState` the browser adapter builds, and serves one page with a TV view and a phone view. Ships as one Docker container.

**Tech Stack:** Node 22 (`node:http`, built-in `fetch`, `node:test`), vanilla ES-module page, Docker Compose.

**Spec:** `docs/superpowers/specs/2026-10-12-tv-recaps-design.md`

## Global Constraints

- Zero npm dependencies. Do not run `npm install` or add packages.
- ES modules everywhere (the root `package.json` has `"type": "module"`). Node >= 20 locally, `node:22-alpine` in Docker.
- Code style matches the repo: 2-space indent, single quotes, semicolons, comments that explain *why*.
- No em dashes or en dashes in any new text: page copy, error messages, comments, README, commit messages. Use commas, colons, parentheses or a plain hyphen.
- Nothing hardwired to one network: no real IPs, hostnames or personal paths in committed files. Use `jellyfin.local`, `llm.local`, `tv.local` placeholders.
- Never log or echo API keys, the TV key, or transcript text.
- Default port `8795` (8790 is taken on the dev host).
- `npm test` runs `node --test 'test/**/*.test.js'`; new tests live in `test/tv/`. The 56 existing tests must keep passing.
- Every commit message ends with the trailer below (shown as `<trailer>` in commit steps):

## Review Focus

1. Jellyfin behind a reverse-proxy sub-path (`https://host/jellyfin`): every call must keep `/jellyfin`. Pinned in Task 2 (config) and Task 3 (client).
2. A title with two versions (two `MediaSources`): subtitles must come from the version that is playing (`PlayState.MediaSourceId`), since stream indexes differ. Pinned in Task 4 and Task 5.
3. A TV key with URL-special characters (`+ & #` or spaces) would silently break the button URL: reject it at startup with a hint. Pinned in Task 2.
4. Pressing the button in the first seconds (position before the first subtitle cue): a memory recap, not an error. Pinned in Task 5.
5. The phone asks a question while a newer recap has replaced the one on screen: a clear 409, never an answer about the wrong recap. Pinned in Task 8.

```js
  // any; "Forced" subs only cover foreign-language lines, so they rank last.
  // `lang` is a 2-letter code ("en"); Jellyfin reports 3-letter ISO 639-2 codes
  // ("eng"), which the prefix match covers. Callers pass text streams only.
  // Shared by the Jellyfin adapter (browser language) and the TV service
  // (SUBTITLE_LANG).
  globalThis.TDDW.pickJellyfinSubtitleStream = function (streams, lang) {
    const want = (lang || 'en').slice(0, 2).toLowerCase();
    const score = (s) => {
      let n = 0;
      const l = (s.Language || '').toLowerCase();
      if (l.startsWith(want)) n += 4;
      else if (l.startsWith('en')) n += 2;
      if (s.IsDefault) n += 1;
      if (s.IsForced) n -= 3;
      return n;
    };
    return [...(streams || [])].sort((a, b) => score(b) - score(a))[0] || null;
  };
```

```js
// Settings for the TV recap service, read once from environment variables at
// startup. Every problem is collected and reported together, so a bad .env
// fails loudly before the first button press instead of halfway through one.

const SUMMARY_LENGTHS = ['short', 'medium', 'detailed'];
const TRANSCRIPT_BUDGETS = ['standard', 'local'];
const DEFAULT_PORT = 8795;
// The key travels in a URL (the TV button and the phone bookmark), so it has
// to survive a query string untouched: letters, digits, '-' and '_' only.
const URL_SAFE_KEY = /^[A-Za-z0-9_-]{16,}$/;

export class ConfigError extends Error {
  constructor(problems) {
    super(`TD;DW TV can't start. Fix these settings:\n${problems.map((p) => `  - ${p}`).join('\n')}`);
    this.name = 'ConfigError';
    this.problems = problems;
  }
}

export function loadConfig(env = process.env) {
  const problems = [];
  const read = (name) => (env[name] ?? '').trim();

  const required = (name) => {
    const value = read(name);
    if (!value) problems.push(`${name} is required`);
    return value;
  };

  const httpUrl = (name) => {
    const value = required(name);
    if (!value) return '';
    let ok = false;
    try {
      const { protocol } = new URL(value);
      ok = protocol === 'http:' || protocol === 'https:';
    } catch { /* reported below */ }
    if (!ok) problems.push(`${name} must be an http:// or https:// URL (got "${value}")`);
    return value.replace(/\/+$/, '');
  };

  const flag = (name, fallback) => {
    const value = read(name).toLowerCase();
    if (!value) return fallback;
    if (['true', '1', 'yes', 'on'].includes(value)) return true;
    if (['false', '0', 'no', 'off'].includes(value)) return false;
    problems.push(`${name} must be true or false (got "${env[name]}")`);
    return fallback;
  };

  const oneOf = (name, allowed, fallback) => {
    const value = read(name).toLowerCase();
    if (!value) return fallback;
    if (allowed.includes(value)) return value;
    problems.push(`${name} must be one of ${allowed.join(', ')} (got "${env[name]}")`);
    return fallback;
  };

  const portNumber = () => {
    const value = read('PORT');
    if (!value) return DEFAULT_PORT;
    const n = Number(value);
    if (Number.isInteger(n) && n >= 1 && n <= 65535) return n;
    problems.push(`PORT must be a whole number from 1 to 65535 (got "${env.PORT}")`);
    return DEFAULT_PORT;
  };

  const jellyfinUrl = httpUrl('JELLYFIN_URL');
  const jellyfinApiKey = required('JELLYFIN_API_KEY');
  const tvKey = required('TDDW_TV_KEY');
  if (tvKey && !URL_SAFE_KEY.test(tvKey)) {
    problems.push('TDDW_TV_KEY must be at least 16 letters, digits, - or _ (generate one with: openssl rand -hex 24)');
  }
  const llmBaseUrl = httpUrl('LLM_BASE_URL');
  const llmModel = required('LLM_MODEL');
  const summaryLength = oneOf('SUMMARY_LENGTH', SUMMARY_LENGTHS, 'medium');
  const transcriptBudget = oneOf('TRANSCRIPT_BUDGET', TRANSCRIPT_BUDGETS, 'standard');
  const spoilerFreeAnswers = flag('SPOILER_FREE_ANSWERS', true);
  const pauseOnRecap = flag('PAUSE_ON_RECAP', true);
  const port = portNumber();

  if (problems.length) throw new ConfigError(problems);

  return Object.freeze({
    port,
    tvKey,
    pauseOnRecap,
    jellyfin: Object.freeze({
      url: jellyfinUrl,
      apiKey: jellyfinApiKey,
      device: read('JELLYFIN_DEVICE') || null,
      subtitleLang: read('SUBTITLE_LANG') || 'en'
    }),
    // Same shape as the extension's stored config (background/config.js), so
    // the extension's providers and prompts take it unchanged.
    llm: Object.freeze({
      baseUrl: llmBaseUrl,
      apiKey: read('LLM_API_KEY'),
      model: llmModel,
      summaryLength,
      recapProvider: 'auto',
      spoilerFreeAnswers,
      transcriptBudget
    })
  });
}
```

```js
// Fake fetch for the TV service tests: maps "METHOD url" to a canned response.
// A route value can be a string (text 200), { status } alone (empty response
// with that status), an Error (network failure) or anything else (JSON 200).
// Unknown routes answer 404.
export function fakeFetch(routes) {
  const calls = [];
  async function fetchImpl(url, init = {}) {
    const method = init.method || 'GET';
    calls.push({ url: String(url), method, headers: init.headers || {} });
    const key = `${method} ${url}`;
    if (!Object.hasOwn(routes, key)) return new Response(null, { status: 404 });
    const value = routes[key];
    if (value instanceof Error) throw value;
    if (typeof value === 'string') return new Response(value, { status: 200 });
    const keys = value && typeof value === 'object' ? Object.keys(value) : [];
    if (keys.length === 1 && keys[0] === 'status') return new Response(null, { status: value.status });
    return Response.json(value);
  }
  fetchImpl.calls = calls;
  return fetchImpl;
}
```

```js
// Minimal Jellyfin REST client for the TV service: only the calls a recap
// needs. Auth is a server API key (Dashboard > API Keys) sent in the
// documented `Authorization: MediaBrowser Token="..."` header.

export const TICKS_PER_SECOND = 1e7; // Jellyfin ticks are 100-ns units

export class JellyfinError extends Error {
  constructor(message, status = null) {
    super(message);
    this.name = 'JellyfinError';
    this.status = status;
  }
}

export function createJellyfinClient({ url, apiKey }, fetchImpl = globalThis.fetch) {
  const headers = { Authorization: `MediaBrowser Token="${apiKey}"` };
  const id = (value) => encodeURIComponent(value);

  // `url` has no trailing slash (config.js trims it) and every path starts with
  // '/', so plain concatenation keeps a sub-path like https://host/jellyfin.
  async function request(path, method = 'GET') {
    let res;
    try {
      res = await fetchImpl(`${url}${path}`, { method, headers });
    } catch (err) {
      throw new JellyfinError(`Can't reach Jellyfin at ${url} (${err.message})`);
    }
    if (res.status === 401 || res.status === 403) {
      throw new JellyfinError('Jellyfin rejected the API key. Check JELLYFIN_API_KEY.', res.status);
    }
    if (!res.ok) {
      throw new JellyfinError(`Jellyfin ${method} ${path.split('?')[0]} failed (${res.status})`, res.status);
    }
    return res;
  }

  const json = async (path) => (await request(path)).json();

  return {
    getSessions: () => json('/Sessions'),

    getItem: (userId, itemId) => json(`/Items/${id(itemId)}?userId=${id(userId)}`),

    async getResumeItem(userId) {
      const page = await json(`/UserItems/Resume?userId=${id(userId)}&limit=1&mediaTypes=Video`);
      return page?.Items?.[0] || null;
    },

    async getSubtitleVtt(itemId, mediaSourceId, streamIndex) {
      const path = `/Videos/${id(itemId)}/${id(mediaSourceId)}/Subtitles/${Number(streamIndex)}/Stream.vtt`;
      return (await request(path)).text();
    },

    async pause(sessionId) {
      await request(`/Sessions/${id(sessionId)}/Playing/Pause`, 'POST');
    }
  };
}
```

```js
import { TICKS_PER_SECOND } from './jellyfin.js';

// Decides what to recap. Prefers a session playing video right now; if there
// is none (the TV app may stop playback when a browser opens over it), falls
// back to the user's most recent resume point. sessionId is null for a resume
// point, since there is nothing live to pause.

export class NothingPlayingError extends Error {
  constructor(device) {
    super(device
      ? `Nothing is playing in Jellyfin on "${device}" right now.`
      : 'Nothing is playing in Jellyfin right now.');
    this.name = 'NothingPlayingError';
  }
}

function matchesDevice(session, device) {
  if (!device) return true;
  const needle = device.toLowerCase();
  return [session.DeviceName, session.Client].some(
    (value) => typeof value === 'string' && value.toLowerCase().includes(needle)
  );
}

const lastActive = (session) => Date.parse(session.LastActivityDate) || 0;
const isVideo = (item) => !!item && (!item.MediaType || item.MediaType === 'Video');
const ticksToSeconds = (ticks) => (Number(ticks) || 0) / TICKS_PER_SECOND;

export async function findNowPlaying(jellyfin, device) {
  const sessions = (await jellyfin.getSessions())
    .filter((s) => s.UserId && matchesDevice(s, device))
    .sort((a, b) => lastActive(b) - lastActive(a));

  const live = sessions.find((s) => isVideo(s.NowPlayingItem));
  if (live) {
    return {
      sessionId: live.Id,
      userId: live.UserId,
      item: await jellyfin.getItem(live.UserId, live.NowPlayingItem.Id),
      mediaSourceId: live.PlayState?.MediaSourceId || null,
      positionSeconds: ticksToSeconds(live.PlayState?.PositionTicks),
      fromResumePoint: false
    };
  }

  const recent = sessions[0];
  const resume = recent ? await jellyfin.getResumeItem(recent.UserId) : null;
  if (!resume) throw new NothingPlayingError(device);
  return {
    sessionId: null,
    userId: recent.UserId,
    // The resume list leaves out MediaSources and MediaStreams, so load the full item.
    item: await jellyfin.getItem(recent.UserId, resume.Id),
    mediaSourceId: null,
    positionSeconds: ticksToSeconds(resume.UserData?.PlaybackPositionTicks),
    fromResumePoint: true
  };
}
```

```js
import { randomUUID } from 'node:crypto';
import { pickProvider } from '../../background/providers/index.js';
import { buildQuestionMessages } from '../../background/providers/prompts.js';
import { chatCompletion } from '../../background/llm-client.js';
import { TICKS_PER_SECOND } from './jellyfin.js';
import { findNowPlaying } from './now-playing.js';
import {
  parseJellyfinSubtitles,
  pickJellyfinSubtitleStream,
  capTranscript,
  TRANSCRIPT_BUDGET_CHARS
} from './shared.js';

// The extension's recap engine, unchanged: pickProvider sends a real transcript
// to the transcript provider and no transcript to memory mode. Injectable so
// tests never call a real LLM.
export const defaultEngine = {
  recap: (videoState, llm) => pickProvider(videoState, llm).getRecap(videoState, llm),
  answer: (messages, llm) => chatCompletion(llm, messages, { effort: 'medium' })
};

// The same videoState the browser's Jellyfin adapter builds, minus the transcript.
export function describeItem(item, positionSeconds) {
  const isEpisode = item.Type === 'Episode';
  return {
    service: 'Jellyfin',
    title: (isEpisode ? item.SeriesName : item.Name) || 'Unknown title',
    episodeInfo: isEpisode
      ? `S${item.ParentIndexNumber ?? '?'}:E${item.IndexNumber ?? '?'}${item.Name ? ` - ${item.Name}` : ''}`
      : null,
    currentTimeSeconds: positionSeconds,
    durationSeconds: item.RunTimeTicks ? item.RunTimeTicks / TICKS_PER_SECOND : null
  };
}

// The item's best text subtitle track, cut at the position and capped to the
// budget. Uses the media source that is actually playing, because a title
// with two versions numbers its streams differently. Returns null when there
// are only image subs (PGS/VOBSUB), no subs, or no cue before the position;
// the recap then comes from memory.
export async function loadTranscript(jellyfin, item, { mediaSourceId, positionSeconds, subtitleLang, transcriptBudget }) {
  const sources = item.MediaSources || [];
  const source = sources.find((s) => s.Id === mediaSourceId) || sources[0] || null;
  const streams = (source?.MediaStreams || item.MediaStreams || []).filter(
    (s) => s.Type === 'Subtitle' && s.IsTextSubtitleStream
  );
  const stream = pickJellyfinSubtitleStream(streams, subtitleLang);
  if (!stream) return null;

  const vtt = await jellyfin.getSubtitleVtt(item.Id, source?.Id || item.Id, stream.Index);
  const parsed = parseJellyfinSubtitles(vtt, positionSeconds * 1000, stream.Language);
  if (!parsed) return null;

  const budget = TRANSCRIPT_BUDGET_CHARS[transcriptBudget] || TRANSCRIPT_BUDGET_CHARS.standard;
  const { text, truncated } = capTranscript(parsed.lines, budget);
  return { text, language: parsed.language, autoGenerated: false, truncated };
}

export function createRecapService({ jellyfin, config, engine = defaultEngine, log = console }) {
  async function recap() {
    const now = await findNowPlaying(jellyfin, config.jellyfin.device);

    if (now.sessionId && config.pauseOnRecap) {
      try {
        await jellyfin.pause(now.sessionId);
      } catch (err) {
        // Not worth failing the recap over; the viewer can pause by hand.
        log.warn(`[tv] could not pause the TV: ${err.message}`);
      }
    }

    const videoState = describeItem(now.item, now.positionSeconds);
    let subtitleNote = null;
    try {
      videoState.transcript = await loadTranscript(jellyfin, now.item, {
        mediaSourceId: now.mediaSourceId,
        positionSeconds: now.positionSeconds,
        subtitleLang: config.jellyfin.subtitleLang,
        transcriptBudget: config.llm.transcriptBudget
      });
    } catch (err) {
      // Fall back to memory mode, but say so on the page instead of quietly
      // handing over a less trustworthy recap.
      videoState.transcript = null;
      subtitleNote = `Couldn't load the subtitles (${err.message}), so this recap is from memory.`;
      log.warn(`[tv] subtitle load failed: ${err.message}`);
    }

    const result = await engine.recap(videoState, config.llm);
    return {
      id: randomUUID(),
      createdAt: new Date().toISOString(),
      videoState,
      result,
      fromResumePoint: now.fromResumePoint,
      subtitleNote,
      history: []
    };
  }

  function ask(record, question) {
    const messages = buildQuestionMessages(
      record.videoState,
      config.llm,
      record.result.recapText,
      record.history,
      question
    );
    return engine.answer(messages, config.llm);
  }

  return { recap, ask };
}
```

```js
// The latest recap and its follow-up thread, held in memory. One slot: this
// serves one TV, and a restart clearing it is fine. A recap asked for while
// another is running joins it instead of paying for a second LLM call (the TV
// and the phone can both ask at once).

export const MAX_HISTORY = 50; // the prompt only sends the last 10 anyway

export function createStore(runRecap) {
  let latest = null;
  let inFlight = null;

  return {
    recap() {
      if (!inFlight) {
        inFlight = (async () => {
          try {
            latest = await runRecap();
            return latest;
          } finally {
            inFlight = null;
          }
        })();
      }
      return inFlight;
    },

    async latest() {
      if (inFlight) {
        try {
          return await inFlight;
        } catch {
          // The caller that started it gets the error; readers get the previous recap.
        }
      }
      return latest;
    },

    isRunning: () => inFlight !== null,

    addTurn(id, question, answer) {
      if (!latest || latest.id !== id) return false;
      latest.history.push({ question, answer });
      if (latest.history.length > MAX_HISTORY) {
        latest.history.splice(0, latest.history.length - MAX_HISTORY);
      }
      return true;
    }
  };
}
```

```js
// Recap text from the model, turned into plain data the page renders as text
// nodes. Mirrors the extension overlay (content/ui/overlay.js: showRecap,
// renderItem, appendRich): strip list markers, lift a leading [m:ss] into a
// chip, honour **bold** and nothing else. It never builds HTML, so model
// output can't inject markup. Shared by the page and the Node tests.

// `*` is only a bullet when it's a lone asterisk, so a line that opens with
// **bold** keeps both of its markers.
const LIST_MARKER = /^\s*(?:[-•]|\*(?!\*)|\d+[.)])\s*/;
const TIME_CHIP = /^\[(\d{1,2}(?::\d{2}){1,2})\]\s*/;

// "a **b** c" -> [{ text: 'a ', bold: false }, { text: 'b', bold: true }, { text: ' c', bold: false }]
export function splitBold(text) {
  return String(text ?? '')
    .split('**')
    .map((part, i) => ({ text: part, bold: i % 2 === 1 }))
    .filter((run) => run.text);
}

// One entry per non-empty line: { time: '12:34' | null, runs }.
export function parseRecap(recapText) {
  return String(recapText ?? '')
    .split('\n')
    .map((line) => line.replace(LIST_MARKER, '').trim())
    .filter(Boolean)
    .map((line) => {
      const chip = line.match(TIME_CHIP);
      return {
        time: chip ? chip[1] : null,
        runs: splitBold(chip ? line.slice(chip[0].length) : line)
      };
    });
}

// Seconds to "m:ss" or "h:mm:ss", the same format the prompts use.
export function formatTime(seconds) {
  if (!Number.isFinite(seconds)) return '?';
  const s = Math.floor(seconds);
  const h = Math.floor(s / 3600);
  const m = Math.floor((s % 3600) / 60);
  const ss = String(s % 60).padStart(2, '0');
  return h > 0 ? `${h}:${String(m).padStart(2, '0')}:${ss}` : `${m}:${ss}`;
}
```

```js
import { createHash, timingSafeEqual } from 'node:crypto';

// The page URL carries the key as ?key= (a TV button or phone bookmark can't
// set headers); the page's own API calls send it as a Bearer header.

// Hashing both sides gives equal-length buffers, so timingSafeEqual never
// throws on a length mismatch and the comparison time says nothing about it.
export function keyMatches(given, expected) {
  if (!given || !expected) return false;
  const a = createHash('sha256').update(String(given)).digest();
  const b = createHash('sha256').update(String(expected)).digest();
  return timingSafeEqual(a, b);
}

export function isAuthorized(req, url, expected) {
  const bearer = /^Bearer\s+(\S+)\s*$/i.exec(req.headers.authorization || '')?.[1];
  return keyMatches(bearer, expected) || keyMatches(url.searchParams.get('key'), expected);
}
```

```js
// HTTP layer: routing, the key check, body limits and security headers. The
// recap work lives in the store and recap service passed in, so tests drive
// this with fakes.

const MAX_BODY_BYTES = 16 * 1024;
export const MAX_QUESTION_CHARS = 2000;

const STATIC_FILES = {
  'app.js': 'text/javascript; charset=utf-8',
  'render.js': 'text/javascript; charset=utf-8',
  'styles.css': 'text/css; charset=utf-8'
};

// The key rides in the page URL, so it must never leak in a Referer header.
// The page only loads its own files, so everything else is locked out.
const SECURITY_HEADERS = {
  'Content-Security-Policy': "default-src 'self'; base-uri 'none'; form-action 'self'; frame-ancestors 'none'",
  'Referrer-Policy': 'no-referrer',
  'X-Content-Type-Options': 'nosniff',
  'Cache-Control': 'no-store'
};

export class HttpError extends Error {
  constructor(status, message) {
    super(message);
    this.name = 'HttpError';
    this.status = status;
  }
}

function send(res, status, body, contentType) {
  res.writeHead(status, { ...SECURITY_HEADERS, 'Content-Type': contentType });
  res.end(body);
}

function sendJson(res, status, data) {
  send(res, status, JSON.stringify(data), 'application/json; charset=utf-8');
}

// Reads the whole body even when it's too large (discarding the excess), so
// the 413 can still be sent. Bailing out of a `for await` loop instead would
// destroy the request, and with it the socket the response needs.
function readJson(req) {
  return new Promise((resolve, reject) => {
    const chunks = [];
    let size = 0;
    req.on('data', (chunk) => {
      size += chunk.length;
      if (size <= MAX_BODY_BYTES) chunks.push(chunk);
    });
    req.on('error', reject);
    req.on('end', () => {
      if (size > MAX_BODY_BYTES) return reject(new HttpError(413, 'Request body is too large.'));
      const raw = Buffer.concat(chunks).toString('utf8');
      let body;
      try {
        body = raw ? JSON.parse(raw) : {};
      } catch {
        return reject(new HttpError(400, 'Request body must be JSON.'));
      }
      if (!body || typeof body !== 'object' || Array.isArray(body)) {
        return reject(new HttpError(400, 'Request body must be a JSON object.'));
      }
      resolve(body);
    });
  });
}

// What the page needs from a stored recap. The transcript stays on the server:
// it can be hundreds of KB and the page never shows it.
export function toClient(record) {
  const { videoState, result } = record;
  return {
    id: record.id,
    createdAt: record.createdAt,
    title: videoState.title,
    episodeInfo: videoState.episodeInfo,
    positionSeconds: videoState.currentTimeSeconds,
    durationSeconds: videoState.durationSeconds,
    transcriptTruncated: !!videoState.transcript?.truncated,
    fromResumePoint: record.fromResumePoint,
    subtitleNote: record.subtitleNote,
    result,
    history: record.history
  };
}

function statusFor(err) {
  if (err instanceof HttpError) return err.status;
  if (err instanceof NothingPlayingError) return 404;
  if (err instanceof JellyfinError) return 502;
  return 500;
}

export function createApp({ config, store, recapService, publicDir, log = console }) {
  async function serveFile(res, name, contentType) {
    send(res, 200, await readFile(join(publicDir, name)), contentType);
  }

  async function route(req, res, url) {
    const { pathname } = url;
    const method = req.method;

    if (method === 'GET' && pathname === '/healthz') return sendJson(res, 200, { ok: true });

    if (method === 'GET' && pathname.startsWith('/static/')) {
      const name = pathname.slice('/static/'.length);
      // An allow-list, never a path join on user input: nothing else in public/ is reachable.
      if (!Object.hasOwn(STATIC_FILES, name)) throw new HttpError(404, 'Not found.');
      return serveFile(res, name, STATIC_FILES[name]);
    }

    if (!isAuthorized(req, url, config.tvKey)) {
      throw new HttpError(401, 'Missing or wrong key. Open the full link from your setup, including ?key=');
    }

    if (method === 'GET' && pathname === '/') {
      return serveFile(res, 'index.html', 'text/html; charset=utf-8');
    }

    if (method === 'POST' && pathname === '/api/recap') {
      return sendJson(res, 200, toClient(await store.recap()));
    }

    if (method === 'GET' && pathname === '/api/latest') {
      const record = await store.latest();
      if (!record) throw new HttpError(404, 'No recap yet. Press New recap.');
      return sendJson(res, 200, toClient(record));
    }

    if (method === 'POST' && pathname === '/api/ask') {
      const body = await readJson(req);
      const question = typeof body.question === 'string' ? body.question.trim() : '';
      if (!question) throw new HttpError(400, 'Type a question first.');
      if (question.length > MAX_QUESTION_CHARS) {
        throw new HttpError(400, `Keep questions under ${MAX_QUESTION_CHARS} characters.`);
      }

      const record = await store.latest();
      if (!record?.result?.ok || !record.result.known) {
        throw new HttpError(409, 'There is no recap to ask about yet.');
      }
      if (body.recapId && body.recapId !== record.id) {
        throw new HttpError(409, 'A newer recap replaced this one. Reload the page to ask about it.');
      }

      const answer = await recapService.ask(record, question);
      store.addTurn(record.id, question, answer);
      return sendJson(res, 200, { answer });
    }

    throw new HttpError(404, 'Not found.');
  }

  return async function handle(req, res) {
    const url = new URL(req.url, 'http://localhost');
    try {
      await route(req, res, url);
    } catch (err) {
      const status = statusFor(err);
      if (status >= 500) log.error(`[tv] ${req.method} ${url.pathname} failed: ${err.stack || err.message}`);
      if (res.headersSent) {
        res.destroy();
        return;
      }
      const message = err.message || 'Something went wrong.';
      if (url.pathname.startsWith('/api/')) sendJson(res, status, { error: message });
      else send(res, status, message, 'text/plain; charset=utf-8');
    }
  };
}
```

```js
  const res = await fetch(path, {
    ...init,
    headers: { Authorization: `Bearer ${KEY}`, 'Content-Type': 'application/json' }
  });
  const body = await res.json().catch(() => null);
  if (!res.ok) throw new Error(body?.error || `Request failed (${res.status}).`);

}

function appendRuns(el, runs) {
  for (const run of runs) {
    if (run.bold) {
      const strong = document.createElement('strong');
      strong.textContent = run.text;
      el.append(strong);
    } else {
      el.append(run.text);
    }
  }
}

// --- status line: loader, empty state or error --------------------------------

let loaderTimer = null;

function setStatus(text, kind) {
  const status = $('status');
  status.className = `status ${kind}`;
  status.textContent = text;
  status.hidden = false;
}

function showStatus(text, kind = 'info') {
  clearInterval(loaderTimer);
  loaderTimer = null;
  setStatus(text, kind);
}

// A thinking model can take a minute; a ticking counter shows it's alive.
function startLoader(label) {
  const started = Date.now();
  const tick = () => setStatus(`${label} ${Math.round((Date.now() - started) / 1000)}s`, 'loading');
  clearInterval(loaderTimer);
  tick();
  loaderTimer = setInterval(tick, 1000);
}

function hideStatus() {
  clearInterval(loaderTimer);
  loaderTimer = null;
  $('status').hidden = true;
}

// --- rendering ------------------------------------------------------------------

let current = null;

function clearRecap() {
  $('title').textContent = '';
  $('meta').textContent = '';
  $('recap').hidden = true;
  $('qa').hidden = true;
}

function renderHeader(rec) {
  $('title').textContent = rec.title;
  const at = `at ${formatTime(rec.positionSeconds)}${rec.durationSeconds ? ` of ${formatTime(rec.durationSeconds)}` : ''}`;
  const parts = [rec.episodeInfo, at, rec.fromResumePoint ? 'from your resume point' : null];
  $('meta').textContent = parts.filter(Boolean).join(' · ');
}

function bulletNode(bullet) {
  const li = document.createElement('li');
  if (bullet.time) {
    const chip = document.createElement('span');
    chip.className = 'chip';
    chip.textContent = bullet.time;
    li.append(chip);
  }
  const text = document.createElement('span');
  appendRuns(text, bullet.runs);
  li.append(text);
  return li;
}

function turnNodes(question, answer) {
  const q = document.createElement('p');
  q.className = 'question';
  q.textContent = question;
  const a = document.createElement('p');
  a.className = 'answer';
  if (answer === null) {
    a.classList.add('pending');
    a.textContent = 'Thinking...';
  } else {
    appendRuns(a, splitBold(answer));
  }
  return [q, a];
}

function renderRecap(rec) {
  current = rec;
  clearRecap();
  renderHeader(rec);
  const { result } = rec;

  if (!result.ok) return showStatus(result.error, 'error');
  if (!result.known) return showStatus(result.message, 'info');
  hideStatus();

  const badge = BADGES[result.source] || BADGES.knowledge;
  const sampled = result.source === 'transcript' && rec.transcriptTruncated ? ' (sampled to fit)' : '';
  $('badge').className = `badge ${badge.cls}`;
  $('badge').textContent = badge.text + sampled;
  $('note').textContent = rec.subtitleNote || '';
  $('note').hidden = !rec.subtitleNote;
  $('bullets').replaceChildren(...parseRecap(result.recapText).map(bulletNode));
  $('recap').hidden = false;

  if (!IS_TV) {
    $('thread').replaceChildren(...rec.history.flatMap((turn) => turnNodes(turn.question, turn.answer)));
    $('qa').hidden = false;
  }
}

// --- actions --------------------------------------------------------------------

async function newRecap() {
  const button = $('new-recap');
  button.disabled = true;
  clearRecap();
  startLoader('Catching you up...');
  try {
    renderRecap(await api('/api/recap', { method: 'POST' }));
  } catch (err) {
    showStatus(err.message, 'error');
  } finally {
    button.disabled = false;
  }
}

async function loadLatest() {
  startLoader('Loading the latest recap...');
  try {
    renderRecap(await api('/api/latest'));
  } catch (err) {
    showStatus(err.message, 'info');
  }
}

function setAsking(busy) {
  $('ask-input').disabled = busy;
  $('ask-button').disabled = busy;
}

async function ask(event) {
  event.preventDefault();
  const input = $('ask-input');
  const question = input.value.trim();
  if (!question || !current) return;

  const [q, a] = turnNodes(question, null);
  $('thread').append(q, a);
  input.value = '';
  setAsking(true);
  try {
    const { answer } = await api('/api/ask', {
      method: 'POST',
      body: JSON.stringify({ question, recapId: current.id })
    });
    a.className = 'answer';
    a.replaceChildren();
    appendRuns(a, splitBold(answer));
  } catch (err) {
    a.className = 'answer error';
    a.textContent = err.message;
  } finally {
    setAsking(false);
    input.focus();
  }
}

document.body.classList.toggle('tv', IS_TV);
if (IS_TV) {
  $('tv-hint').hidden = false;
  newRecap();
} else {
  $('new-recap').hidden = false;
  $('new-recap').addEventListener('click', newRecap);
  $('ask-form').addEventListener('submit', ask);
  loadLatest();
}
```
